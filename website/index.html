Technical Architecture & Stack

Engineered for zero-latency desktop and browser execution with zero external runtime dependencies.

🦀 Rust Tauri v2 Backend

Sub-millisecond stochastic mathematical market engine using tokio asynchronous tasks, geometric Brownian motion drift, and Poisson jump diffusions.

⚡ Vue 3 + Pinia + Tailwind

High-performance reactive frontend with procedural SVG candlestick chart rendering, order book depth calculation, and Bloomberg terminal aesthetic.

🔊 Web Audio API Synthesizer

Zero MP3/WAV audio file overhead. All buy, sell, news alerts, pumps, and dumps are synthesized dynamically using oscillators and gain envelopes.

Download & Quickstart

Run Simange locally on Windows, Linux, or directly in your browser.

# 1. Clone & Install dependencies with Bun
git clone https://github.com/username/simange.git
cd simange && bun install
# 2. Run in Desktop Mode (Tauri)
bun run tauri dev
# 3. Or Run in Web Browser Only
bun run dev
